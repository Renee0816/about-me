# About Me: Renee Konstantine

My personal one-page website. I'm a Certified Reverse Mortgage Professional (CRMP) with 20+ years in mortgage lending, and I'm moving into AI support engineering.

The page covers my background, credentials, strengths, career journey, skills, and what I'm currently learning.

## How to open it

The whole site is a single file, `index.html`. No installation or build step is needed.

- **On your computer:** double-click `index.html` and it opens in your web browser.
- **From GitHub:** download the repository (green **Code** button → **Download ZIP**), unzip it, and double-click `index.html`.
